# آنلاک بوتلودر باند ۱ (مورد نیاز برای روت و نصب کاستوم رام)

!!! warning "هشدار مهم"
با آنلاک بوتلودر، **تمام اطلاعات گوشی شما حذف خواهد شد**.
حتماً قبل از شروع، از فایل‌ها و اطلاعات مهم خود **پشتیبان بگیرید**.

گوشی **Daria Bond** بسیار نزدیک به اندروید خام است و آنلاک بوتلودر آن به‌سادگی با دستور زیر انجام می‌شود:

```bash
fastboot flashing unlock
```

اما قبل از رسیدن به این مرحله، باید چند مرحله‌ی آماده‌سازی را انجام دهید.

---

## مراحل آنلاک بوتلودر

### ۱. فعال کردن Developer Options و USB Debugging

1. وارد **Settings** شوید.
2. به مسیر **About phone → Build number** بروید.
3. روی **Build number** چند بار (حدود ۷ بار) بزنید تا پیام *“You are now a developer!”* ظاهر شود.
4. به مسیر **Settings → System → Developer options** بروید.
5. گزینه‌های زیر را فعال کنید:

   * **OEM unlocking**
   * **USB debugging**

---

### ۲. نصب ADB و Fastboot روی کامپیوتر

برای ارتباط با گوشی از طریق USB به ابزارهای **ADB** و **Fastboot** نیاز دارید.

<summary>💻 نصب درایور و ADB و Fastboot روی ویندوز</summary>

اگر از ویندوز استفاده می‌کنید، می‌توانید ابزارهای مورد نیاز و درایور را از لینک زیر دریافت و نصب کنید:

<a href="https://t.me/dariabond_group/62787">دانلود و نصب درایور و ADB</a>

</details>

<details>
<summary>🐧 نصب ADB و Fastboot روی لینوکس</summary>

<h3>Debian / Ubuntu:</h3>

```bash
sudo apt update
sudo apt install android-tools-adb android-tools-fastboot
```

<h3>Fedora:</h3>

```bash
sudo dnf install android-tools
```

<h3>Arch Linux:</h3>

```bash
sudo pacman -S android-tools
```

پس از نصب، با دستور زیر می‌توانید نصب ADB را بررسی کنید:

```bash
adb version
```

</details>

### ۳. ورود به Fastboot Mode

اگر از ویندوز استفاده می‌کنید، وارد پوشه‌ی **platform-tools** (که در مرحله‌ی ۲ دانلود کرده‌اید) شوید.

در فایل منیجر، روی نوار آدرس بالای صفحه کلیک کنید، عبارت `cmd` را وارد کرده و Enter بزنید تا Command Prompt در همان پوشه باز شود.

1. گوشی را با کابل USB به کامپیوتر متصل کنید.

2. در ترمینال دستور زیر را اجرا کنید:

   ```bash
   adb devices
   ```

   اگر روی گوشی پیغامی مبنی بر اجازه‌ی دسترسی USB Debugging نمایش داده شد، گزینه‌ی **Allow** را انتخاب کنید.

   این دستور نشان می‌دهد که آیا گوشی توسط ADB شناسایی شده است یا خیر.

   در صورت شناسایی صحیح، خروجی باید چیزی مشابه این باشد:

   ```text
   $ adb devices
   List of devices attached
   ABP1B0000178011432E     device
   ```

3. پس از اطمینان از شناسایی گوشی، با دستور زیر وارد Bootloader شوید:

   ```bash
   adb reboot bootloader
   ```

4. منتظر بمانید تا گوشی وارد حالت **Fastboot** شود. در این حالت معمولاً عبارت **FASTBOOT MODE** روی صفحه نمایش داده می‌شود.

---

### ۴. آنلاک بوتلودر

برای **Bond 1** کافی است گوشی را در حالت Fastboot قرار داده و دستور زیر را اجرا کنید:

```bash
fastboot flashing unlock
```

روی گوشی پیغام تأیید ظاهر می‌شود.

با استفاده از کلیدهای **Volume** گزینه‌ی تأیید را انتخاب کنید تا فرایند آنلاک آغاز شود.

!!! warning "توجه"
با تأیید آنلاک، تمام اطلاعات کاربر گوشی پاک خواهد شد.

پس از پایان فرایند، گوشی ریست می‌شود و بوتلودر آنلاک خواهد شد. ✅

#### Bond II و Bond II Lite

برای گوشی‌های **Bond II** و **Bond II Lite** ابتدا باید فایل `signature.bin` را از پشتیبانی سایت داریا دریافت کرده و آن را طبق دستورالعمل مربوط به این مدل‌ها فلش کنید.

```bash
fastboot flash signature.bin <file_address>
```

به‌جای `<file_address>` باید مسیر فایل `signature.bin` را وارد کنید.

در ویندوز می‌توانید فایل را با ماوس گرفته و داخل ترمینال بکشید تا مسیر فایل به‌صورت خودکار وارد شود.

پس از انجام این مرحله، دستور زیر را اجرا کنید:

```bash
fastboot flashing unlock
```

روی گوشی پیغام تأیید ظاهر می‌شود. با استفاده از کلیدهای **Volume** تأیید کنید تا فرایند آنلاک آغاز شود.

!!! warning "توجه"
آنلاک بوتلودر باعث پاک شدن تمام اطلاعات کاربر می‌شود.

---

### ۵. بوت مجدد به اندروید

اگر گوشی به‌صورت خودکار ریبوت نشد، می‌توانید با اجرای دستور زیر آن را ریبوت کنید:

```bash
fastboot reboot
```

گوشی دوباره روشن می‌شود.

در صفحه‌ی بوت ممکن است پیامی مانند *“Bootloader is unlocked”* نمایش داده شود که نشان‌دهنده‌ی آنلاک بودن بوتلودر است. 🎉

---

## قفل کردن مجدد بوتلودر

در صورت نیاز به قفل کردن مجدد بوتلودر، ابتدا **حتماً رام رسمی و فایل‌های مورد نیاز دستگاه را فلش کنید**.

!!! danger "هشدار مهم"
قبل از قفل کردن مجدد بوتلودر، مطمئن شوید که رام رسمی روی گوشی نصب شده است. قفل کردن بوتلودر در حالی که رام یا ایمیج‌های غیررسمی یا دستکاری‌شده روی دستگاه قرار دارند، می‌تواند باعث عدم بوت شدن گوشی شود.

پس از اطمینان از نصب رام رسمی، برای قفل کردن مجدد بوتلودر دستور زیر را اجرا کنید:

```bash
fastboot flashing lock
```

روی گوشی پیام تأیید نمایش داده می‌شود. پس از تأیید، بوتلودر دوباره قفل خواهد شد و اطلاعات کاربر نیز پاک می‌شود.

---
